# Seseragi

The design philosophy of Seseragi is centered around "page calming" ideas, emphasizing readability and creating a visually calm experience. It does this through use of whitespace for separation of content elements and for visual rhythm and typography for form. It is minimalist in the sense of avoiding unnecessary decorations and distractions.

# Seseragi Minimal

The basic design with a minimal feature set. It supports the modular stacking sections pages and offers two different semantics, DIV and SECTION.
